# AccessEvent — Инклюзивная платформа мероприятий

AccessEvent — это веб-платформа для организации и проведения мероприятий с фокусом на доступность для людей с нарушениями слуха.

## Цели проекта
- Равный доступ к событиям для глухих и слабослышащих людей.
- Удобное создание и модерация инклюзивных мероприятий.
- Визуальные цветные оповещения и текстовые чаты вместо звука.

## Стек технологий
- Backend: Python 3.10+, Flask 2.3+
- База данных: PostgreSQL 14+, SQLAlchemy ORM
- Шаблонизатор: Jinja2
- CI/CD: GitHub Actions, GHCR
- Тесты: pytest
